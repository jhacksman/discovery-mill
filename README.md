# Discovery Mill

Investigation and specification for an independent, open-source, local
discovery-processing application: import → preserve originals → inventory/metadata →
page images → text/OCR → QC → numbering/endorsement → validated production exports
(images, text, metadata, natives, load files).

This repository currently holds the **research and specification phase**. See
`PROGRAM.md` (objective, scope, decisions, milestones), `BACKLOG.md`, `CHECKPOINT.md`,
and `docs/research/`. No vendor binaries or raw analysis material are stored here; see
`docs/research/environment.md`.
